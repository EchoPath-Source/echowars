# Echo Wars Publisher Brief — Working Summary

_Source reference: `EchoWars_Publisher_Brief.docx`_

## Product frame
**Echo Wars: Resonance Clash** is positioned as a real-time 1v1 mobile card battler set in the wider Echo Wars IP. It inherits its lore from the tabletop setting while reshaping the core loop for mobile readability and repeatable matches.

## Key differentiator
Unlike standard destruction-only lane battlers, Echo Wars introduces:
- **Drift** — low-health units become vulnerable to conversion
- **Conversion** — enemy units can flip sides instead of only dying
- **Ascend** — surviving units evolve during the match
- **Alignment score** — post-match evaluation can reflect more than raw tower damage
- **Field logic** — the battlefield behaves like a living scalar field, not a static backdrop

## Arena summary
- Vertical mobile arena
- Two primary lanes plus a center node / center pressure path
- Veil Anchors as the core tower structure
- Battlefield events respond to what happens in the match rather than remaining decorative

## Commercial value proposition
The pitch is not just "another fantasy card battler."
The value comes from:
- different win logic
- spatial identity through faction movement
- convert-and-return moments that are visually memorable
- strong worldbuilding already seeded through tabletop canon
- room for legendary Echoforms and live content expansions later

## Faction roster frame
The publisher-facing material should keep the four founding factions readable at a glance:
- Awakened Ones — remembrance / coherence
- Loopbound — erosion / recursion
- Architects of Collapse — control / measure
- Forgotten Flame — vow / return through ruin

## Internal guidance
- Keep player-facing language mythic and readable.
- Keep internal field/pathing language separate.
- Build the first prototype around a narrow, polished roster before expanding to the full card pool.
