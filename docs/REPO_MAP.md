# Echo Wars Repo Map

## Purpose
This repository is the working home for the Echo Wars mobile/tabletop project. It is being set up around text-friendly design docs first so the project is easy to diff, search, and evolve in GitHub.

## Current structure
- `docs/` — build specs, canon, publisher-facing summaries, and art direction
- `assets/cards/` — card asset notes, source sync notes, and UI asset planning
- `roster/` — current unit ladder and baseline art references
